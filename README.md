# Scaffold Stacks Donations

A small donation app for supporting the Scaffold Stacks open-source project. Donors connect a Stacks wallet, choose an amount in STX, and approve an on-chain transfer to the contract's treasury. The app displays aggregate donation totals and, when a wallet is connected, that wallet's recorded contribution.

## How donations work

- `donate(amount)` transfers the specified positive amount of micro-STX from the caller to the contract deployer, which is the contract's fixed treasury.
- The contract records the total amount received, the number of successful donations, and each donor's cumulative amount.
- Read-only functions expose the treasury address, overall total, donation count, and a donor's total.
- The frontend uses a wallet post-condition to constrain the STX transfer to the amount selected.
- Donations are on-chain and irreversible once confirmed. The network transaction fee is separate from the donation amount.

## Run locally

Requirements: Node.js 20+, Rust, Clarinet 3.23+, and the `stacksdapp` CLI. Docker is only needed for Scaffold Stacks devnet workflows.

Install dependencies if they are not already installed:

```bash
npm --prefix contracts install
npm --prefix frontend install
```

Run the frontend against the deployed testnet contract:

```bash
printf 'NEXT_PUBLIC_NETWORK=testnet\n' > frontend/.env.local
npm --prefix frontend run dev
```

Open [http://localhost:3000](http://localhost:3000) and connect a Stacks wallet configured for testnet. You will need testnet STX to donate and pay transaction fees.

To use devnet instead, start the Scaffold Stacks devnet workflow with `stacksdapp dev --auto-deploy` and follow the CLI output. The frontend network must match the network where the contract is deployed.

## Development commands

Run from the repository root:

```bash
stacksdapp check       # Type-check Clarity contracts
stacksdapp generate    # Regenerate frontend contract bindings
stacksdapp test        # Run contract and frontend test suites
npm --prefix frontend run typecheck
npm --prefix frontend run build
```

The Clarity contract source is in `contracts/contracts/donation.clar`; its tests are in `contracts/tests/donation.test.ts`. The custom donation interface is in `frontend/src/components/DonationExperience.tsx`. Files under `frontend/src/generated/` are generated by `stacksdapp generate` and should not be edited by hand.

## Deploying a new instance

For a new testnet deployment, configure a **new, securely stored testnet deployer mnemonic** in `contracts/settings/Testnet.toml` without committing it, then run:

```bash
stacksdapp check
stacksdapp generate
stacksdapp test
stacksdapp deploy --network testnet --yes
```

Deployment updates the generated contract metadata and hooks. The treasury is fixed to the deployer at contract publication time; deploy with the intended treasury account.
